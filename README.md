# Vue Timeline Editor

A lightweight, flexible, and interactive timeline editor for Vue 3.

Designed for building booking systems, schedulers, and resource timelines with full control over UI and behavior.

---

## ✨ Features

- 📅 Horizontal timeline (time-based grid)
- 🧱 Multi-row support (tables/resources/zones)
- 🖱 Drag to move bookings
- ↔️ Resize bookings (start/end)
- ➕ Click to create booking
- 🔍 Zoom (dynamic time scale)
- 🎯 Snap to grid (configurable)
- 🎨 Fully customizable via slots
- ⚡ High-performance (DOM + transform-based rendering)
